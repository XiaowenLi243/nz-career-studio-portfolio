# NZ Career Studio · Portfolio Prototype

A personal job search dashboard designed around a job seeker's workflow: review opportunities, shortlist roles, compare options, and track applications.

## Run locally

Open `index.html` in a browser. The prototype uses fictional records and requires no account or installation.

## What this prototype demonstrates

- A collapsible sidebar and a job detail panel that preserves the list view
- Shortlisting and comparison interactions
- A single-file interface built with HTML, CSS, and vanilla JavaScript

## Project context

I defined the job search workflow, set the interaction requirements, and refined the design through hands-on feedback. I used ChatGPT and Codex to assist with implementation and iterated on a private version hosted with ChatGPT Sites.

This repository contains the standalone interaction prototype. The private deployment and its integrations are separate.

## Read the code

Start with the HTML for navigation and layout, then read the CSS for responsive panels and the JavaScript for selection, filtering, and rendering.
